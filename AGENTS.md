- Navigation par canal (Vue réseau, Live, Uber/Deliveroo/Caisse/Dishop/Chataigne) intégrée dans la sidebar gauche via OverviewChannelSidebar ; Overview lit ?channel= dans l'URL. Pourquoi : une seule sidebar, plus de colonne en double.

Les RPC isolent l'enseigne ; ne pas déduire un tarif de vente à partir d'une commande. Pourquoi : conserver des références de prix explicites sans écraser les historiques ni les grilles caisse.
- L'identité de l'enseigne (nom + logo) vit dans le sélecteur de chaîne de la sidebar ; l'en-tête principal reste neutre. Pourquoi : éviter de répéter la marque et garder une seule zone de contexte.

- Vue réseau (/overview, canal global) : présentation dédiée dans NetworkRevenueHero + NetworkChannelCards + NetworkComparisonTable, alimentée par useNetworkDailyRevenue (RPC get_daily_revenue_from_orders / get_daily_onsite_from_splash / get_daily_chataigne). Pourquoi : direction artistique « logiciel financier » sans toucher aux vues par canal, qui gardent ChannelRevenueTiles / RestaurantComparisonTable.
